# 分块查找
分块查找将待查找数据分为若干块，块间有序而块内可以无序，优先索引到数据所在的块，然后在块内少量数据执行顺序查找
平均查找长度为索引查找的平均长度和块内查找的平均长度之和
$$
	ASL = L_{1}+L_{s}

$$
假设查找表均匀的分成$b$块，每块里有$s$条记录，对块索引和块内索引均采用顺序查找，那么
$$
	ASL = \frac{{b+1}}{2}+\frac{{s+1}}{2} = \frac{{s ^{ 2}+2s+n}}{2s} (n = bs)
$$
分块查找的块大小最优值在$s = \sqrt{ n }$，可以令平均查找长度达到最小值

# 二叉排序树
删除二叉排序树中的某个分支节点的时候，若左子树空则用右孩子填补，右子树空则用左子树填补，若左右子树都不空则在右子树上找中序第一个孩子填补，转化至删除右子树上的节点

# 红黑树
平衡树插入需要频繁的调整树的结构，导致效率低下，因此引入红黑树
条件：
	每个节点或是红色或是黑色
	根节点是黑的，叶子节点（虚构的）也是黑色的
	不存在两个相邻的红色节点
	对每个节点，从该节点到任意一个叶节点的简单路径上，黑色节点的数量相同
结论：
	从根到叶的最长路径不大于最短路径的两倍（红黑交替）
	有n个内部节点的红黑树高度$h\leq 2\log_{2}(n+1)$（每条路径至少有一半为黑，黑高为$\frac{h}{2}$）
