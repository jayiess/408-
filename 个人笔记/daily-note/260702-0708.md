# 最短路径
广度优先搜索算法可用于求解无权图的最短路径，也即所有边的权值相同
Dijkstra算法
	1. 从初始点$v_{0}$开始求解，每次记录与$v_{0}$有路径的点的距离，没有路径的点的距离是正无穷
	2. 挑一个所有已知距离里面最短的，这个路径就是第二个已经求出的最短路径，然后再更新与这个点有路径的所有点
	3. 重复步骤，直至所有点都已经求出最短路径
	**这个算法不适用于求解存在负权边的图，因为假设第一次求出了$v_{0}$到$v_{1}$和$v_{2}$的距离，取了$v_{1}$的距离为已求出的最小距离，第二次更新的时候发现$v_{2}$到$v_{1}$的距离为负数，也就是说可能会小于第一次已求出的路径**
	
Floyd算法
	1. 迭代生成一系列方阵$A_{1},A_{2},A_{3}\dots A_{k}$，其中$A_{k}[i][j]$表示从顶点$v_{i}$到$v_{j}$允许使用编号不超过k的顶点作为中间值的最短路径长度
	2. 每次都考虑在每个路径中间添加一个$v_{k}$作为中间点，看看能不能把路径缩短，然后一直迭代下去，直到考虑完所有的点
	**不允许存在负权环，因为每次迭代都可以一直选一条有负权的路径，就可以把距离降到无穷小**

# 拓扑排序
每次选择一个入度为0的点进行排序，选择完之后就把这个点以及其相邻的边给去掉
存在拓扑排序表示这个有向图里没有环

# 关键路径
AOE网带权值
AOV网无权值
考点：求aoe网时间的最早发生时间和最迟发生时间
	首先求最早发生时间，对于每个顶点，选择可到达的最长距离作为以此顶点为起始事件的最早发生时间
	其次求最晚发生时间，从最后一个顶点往前倒推，选择每个前驱顶点能从后驱顶点往回的最小值
 加快关键活动的执行速度有可能可以缩短总工期
 不能任意缩短关键活动的持续时间，主要是看到达某个顶点的最长活动时间，一旦过度缩短可能会引起关键路径的转移
 关键路径可能不止一条，只有加快那些同时出现在关键路径上的关键活动才能缩短工期、
