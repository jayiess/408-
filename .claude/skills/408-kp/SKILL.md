# 408 知识点卡片排版

规则（KP 要素、两个空 callout、禁止 `==高亮==`、禁止本节自测）在 `CLAUDE.md` 「一、拆解知识点」，**此处不重复**。本文件只定排版形态和流程。

## 流程

1. 逐 KP 写卡片，追加到 `知识点/<缩写>-<章号>-<章节名>.md`（缩写 OS / DS / CO / CN）。同章后续小节追加进同一文件，KP 编号接着排。

2. 更新 `408学习进度.md`：状态、知识点数、卡片链接、最近学习日期，并在该章的「已拆 / 待拆」行里写明 KP 区间。

## 文件头

```md
# OS 第3章 内存管理

教材：[[王道教材/27 王道操作系统/第3章 内存管理.md]]
本篇覆盖 3.1（内存管理概念）。3.2 虚拟内存管理待拆。

本章主线：**分页提高物理内存利用率 → 请求分页实现虚拟内存**。

---
```

## 标题层级

- `# 3.1 内存管理概念` —— 一级，只给**大节**（3.1、3.2）。
- `## KP2 从源程序到执行：编译、链接、装入（真题）` —— 二级，KP 扁平排列。
- **不给 3.1.1 / 3.1.2 这类子小节单独标题**，KP 标题自己说明内容，子小节归属写进进度表的 KP 区间。
- KP 之间用 `---` 分隔。

标题后缀按真题年份数量：1–2 年 `（真题）`，3–4 年 `（真题高频）`，5 年以上 `（真题超高频）`。计算题可写 `（真题高频，必会算）`。

## KP 样例

```md
## KP2 从源程序到执行：编译、链接、装入（真题）

**真题**：2011 考过编译、链接和装入阶段各自的工作内容。

**核心结论**：用户源程序变成内存中可执行的程序，走三步：

| 步骤 | 谁做 | 做什么 | 产物 |
| --- | --- | --- | --- |
| 编译 | 编译程序 | 翻译源代码 | 若干**目标模块** |
| 链接 | 链接程序 | 合并目标模块 + 所需库函数 | 一个完整的**装入模块** |

教材图示：[[王道教材/27 王道操作系统/pictures/fig-3-1.jpg]]（图 3.1）

**易错点**：**地址重定位不是编译阶段的事**。编译只管翻译，地址调整在链接和装入。

**易错点**：库函数是在**链接**阶段合并进来的，不是编译阶段。

> [!note] 我的笔记
> 

> [!question] 我的问题
> 

---
```

## 排版决策

| 项 | 写法 |
| --- | --- |
| 结论 | `**核心结论**：` 开头。最容易错的那条升格为 `**核心结论（易错重点）**：` |
| 易错点 | 每条独立一段，`**易错点**：` 开头，一条一个错法，不合并 |
| 对比 / 分类 / 步骤 | 一律上表格，别写成散文段落 |
| 教材图 | `教材图示：[[王道教材/…/pictures/fig-x-y.jpg]]（图 x.y 说明）`。**用 `[[]]` 链接，不用 `![[]]` 嵌入** |
| 公式 | 行内 `$P = \lfloor A/L \rfloor$`；`$\geqslant$` 不写成 `>=` |
| 流程 / 判定分支 | 用 ` ```  ``` ` 代码块画树或箭头链，别用嵌套列表 |
| 强调 | 只用 `**加粗**`。禁止 `==高亮==`（那是用户边读边标的） |
| 教材例题 | 保留数字，用表格列出「情形 → 结果」，让用户能自己复算 |

## 粒度

一个 KP = 一个能独立口答的结论块。教材一个 `####` 小标题通常对应 1 个 KP；内容长或含独立计算套路的拆成 2 个（如「地址变换机构」和「页表项大小的确定」分开）。教材小节末尾的「本节小结」单独作最后一个 KP，把小节开头的思考题答案收进去。

一个大节（如 3.1）通常 25–35 个 KP。远少于这个数说明拆粗了。
