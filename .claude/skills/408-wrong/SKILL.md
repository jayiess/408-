# 408 错题录入

录题字段标准、错误类型清单、复查日期规则在 `CLAUDE.md`「三、收录错题」，**此处不重复**。本文件只定「划选全章题目 + 报题号」这个入口的执行流程。

**不要手写 CSV 和章节 md**。`错题库/录入错题.ps1` 已经同时管这两处，手写会和脚本的格式漂移。

## 触发形态

用户划选一整节的习题（通常是 `x.y.5 本节习题精选` + `x.y.6 答案与解析`），然后只报**题号 + 自己选的答案**：

> 我错了 02、04、05，分别选了 A、C、D

题干、选项、正确答案、解析全部**从划选内容里按题号索引**，不要反问用户，也不要让他重复题目。

## 流程

1. **按题号定位**。在划选内容的「本节习题精选」里找题号，在「答案与解析」里找同题号的正确答案和解析。划选没覆盖到答案区时，去 `王道教材/` 对应章节文件里 grep 补齐，别猜答案。

2. **抽字段**。教材选项有两种排版，都要能认：

   ```
   多行式：  - A. 普通文件
             - B. 目录文件

   紧凑式：  - A. 连续文件    B. 系统文件    C. 链接文件    D. 流式文件
   ```

   紧凑式要拆成四项。选项里的公式、代码保留原样。

3. **定错误类型**。用户给了自己的错因就**优先保留他的原话**再归类；没给就按解析和他的错选推断，从 `CLAUDE.md` 那八类里选：概念不清、过程推导错、计算/单位错、审题错、代码边界错、题型陌生、记忆遗漏、时间不够。

4. **组 JSON 数组**，一次录完所有题（见下）。先 `-DryRun` 打印给用户看，确认无误再真写。

5. **落盘 + 补计数器**（两条都要跑）：

   ```powershell
   cd F:\二战\408\错题库
   .\录入错题.ps1 -Json $j          # 写 错题索引.csv + 章节 md
   .\更新复习计数器.ps1              # 给新题建计数行，漏跑前端看不到
   ```

6. **回复**：简短说明录了哪几题、写了哪些文件，然后在对话里讲错因（讲解不写进 md）。若这几题暴露了同一个错法，末尾补一段「本次共同错因」写进章节 md。

## JSON

必填七项 + 常用可选项，批量就传数组：

```powershell
cd F:\二战\408\错题库
$j = @'
[
  {
    "date": "2026-09-04",
    "subject": "OS",
    "chapter": "第4章 文件管理",
    "number": "02",
    "topic": "逻辑结构与物理结构的归属",
    "questionType": "单项选择题",
    "question": "下列说法中，（）属于文件的逻辑结构的范畴。",
    "options": { "A": "连续文件", "B": "系统文件", "C": "链接文件", "D": "流式文件" },
    "answer": "D",
    "myAnswer": "A",
    "wrongType": "概念不清",
    "wrongReason": "把连续文件当成了逻辑结构，实际它是物理结构。",
    "reviewConclusion": "先分清问的是逻辑还是物理：逻辑只有无结构（流式）和有结构（顺序/索引/索引顺序/散列），带「连续/链接/索引分配」字样的一律是物理结构。"
  }
]
'@
.\录入错题.ps1 -Json $j -DryRun
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `subject` | ✓ | 收缩写 `OS` / `DS` / `CO` / `CN`，也收中文全称，写进 CSV 一律中文全称 |
| `chapter` | ✓ | 写成 `第4章 文件管理`，和进度表章名一致 |
| `number` | ✓ | 教材题号，保留前导零（`02` 不写 `2`） |
| `topic` | ✓ | 考点，一句话，会同时进 CSV 和 md 标题 |
| `question` | ✓ | 题干 |
| `answer` | ✓ | 正确答案 |
| `wrongType` | ✓ | 八类之一 |
| `myAnswer` | | 用户的错选 |
| `wrongReason` | | 会渲染成红字，缺省填「待补。」 |
| `reviewConclusion` | | 下次怎么判断，缺省填「待补。」 |
| `options` | | 对象，键是选项字母 |
| `code` | | 代码题的代码块 |
| `imageSource` | | 只有图本身参与解题时才填 |
| `questionType` | | 缺省「单项选择题」，综合应用题要显式写 |
| `date` | | 缺省今天 |
| `reviewDate` | | 缺省 date+1 天 |
| `file` | | 强制指定章节 md 路径，正常不用传 |

## 四个坑

**必须补跑 `更新复习计数器.ps1`**。录题脚本不碰 `复习计数器.csv`，漏跑新题在错题前端里没有计数行。

**没有重复检测**。同题录两遍会在 CSV 加两行、md 追加两个条目。录之前先 `grep` 一下题号确认没录过：

```bash
grep "第4章 文件管理,02," 错题库/错题索引.csv
```

**管道必须带 `-Raw`**。`Get-Content x.json | .\录入错题.ps1` 会按行拆、只收到最后一行，报「Invalid JSON primitive」。用 `-Json` 或 `-InputFile` 最省事。

**`date` 只认 `yyyy-MM-dd`**。走 `ParseExact`，写成 `2026-9-4` 直接抛异常。

## 章节文件路径

脚本自己解析，四科全部章节都在内置映射表里，正常不用传 `file`。解析顺序：CSV 里同章节已有路径 → 内置映射表 → 兜底按 `<缩写>-<章号>-<章名>.md` 生成。新建章节 md 时会自动建目录并往 `错题库/README.md` 的文件结构块插一行。
