# 408 错题库使用说明

以后错题不再全部堆到一个大 Markdown 文件里，改成“索引 + 分章节详解”的结构。

## 文件结构

```text
错题库/
  错题索引.csv
  数据结构/
    DS-01-绪论.md
    DS-02-线性表.md
    DS-03-栈队列数组.md
  周复盘/
```

## 使用方式

- `错题索引.csv`：用来筛选和统计，适合看哪章错得最多、哪类错误最多。
- 分章节 `.md`：保存原题、选项、解析、红色错误原因、图解。
- `周复盘/`：每周生成一份复盘总结。

## 每道错题最低记录标准

1. 日期
2. 科目
3. 王道章节
4. 题号
5. 考点
6. 错误类型
7. 正确答案
8. 原题和选项
9. 红色错误原因
10. 下次遇到同类题第一步

## 错误类型

- 概念不清
- 过程推导错
- 计算/单位错
- 审题错
- 代码边界错
- 题型陌生
- 记忆遗漏
- 时间不够
