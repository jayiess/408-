# 408 错题库使用说明

以后错题不再全部堆到一个大 Markdown 文件里，改成“索引 + 分章节详解”的结构。

日常录题规则见仓库根目录 `CLAUDE.md` 的「三、收录错题」。

## 文件结构

```text
错题库/
  错题索引.csv
  复习计数器.csv
  更新复习计数器.ps1
  录入错题.ps1
  数据结构/
    DS-01-绪论.md
    DS-02-线性表.md
    DS-03-栈队列数组.md
    DS-04-树与二叉树.md
    DS-06-图.md
  操作系统/
    OS-01-计算机系统概述.md
    OS-02-进程与线程.md
    OS-03-内存管理.md
  周复盘/
```

## 操作系统章节文件约定

- 第 1 章 计算机系统概述：`操作系统/OS-01-计算机系统概述.md`
- 第 2 章 进程与线程：`操作系统/OS-02-进程与线程.md`
- 第 3 章 内存管理：`操作系统/OS-03-内存管理.md`
- 后续按 `操作系统/OS-0x-章节名.md` 命名

## 数据结构章节文件约定

- 第 1 章 绪论：`数据结构/DS-01-绪论.md`
- 第 2 章 线性表：`数据结构/DS-02-线性表.md`
- 第 3 章 栈、队列和数组：`数据结构/DS-03-栈队列数组.md`
- 第 5 章 树与二叉树：`数据结构/DS-04-树与二叉树.md`
- 第 6 章 图：`数据结构/DS-06-图.md`

## 使用方式

- `错题索引.csv`：用来筛选和统计，适合看哪章错得最多、哪类错误最多。
- 分章节 `.md`：保存原题、选项、解析、红色错误原因、图解。
- `周复盘/`：每周生成一份复盘总结。

## 错题录入接口

- `录入错题.ps1`：供其他 agent 快速录入错题的统一入口。agent 侧的执行流程见 `408-wrong` skill。
- 从文件录入：`.\录入错题.ps1 -InputFile .\错题.json`
- 直接传字符串：`.\录入错题.ps1 -Json $j`
- 从标准输入录入：`Get-Content .\录入错题.json -Raw | .\录入错题.ps1`（**必须带 `-Raw`**，否则按行拆开、只收到最后一行）
- 只预览不落盘：任意方式加 `-DryRun`
- 传 JSON 数组即批量录入，一次多题。
- 脚本会自动更新 `错题索引.csv` 和对应章节 md；章节文件不存在时自动创建并更新 README。

### 录完必须补跑的一步

`录入错题.ps1` **不写 `复习计数器.csv`**，新题不会自动有计数行。录完接着跑：

```powershell
.\更新复习计数器.ps1
```

装了每日计划任务的话第二天会自动补上，但当天想在错题前端里看到就得手动跑。

### 已知限制

- **无重复检测**：同一题录两遍会在 CSV 加两行、md 追加两个条目。录前先 `grep "<章节>,<题号>," 错题索引.csv` 查一下。
- `date` 只认 `yyyy-MM-dd`（`ParseExact`），写成 `2026-9-4` 会抛异常。
- `wrongType` 是自由文本，不校验下面那八类，写错了会静默录进去。

## 复习计数器

- `复习计数器.csv`：独立计数器，不改变 `错题索引.csv` 的固定列结构。
- `更新复习计数器.ps1`：每天重算“距上次复习天数”和“上次间隔天数”。
  - 手动运行：`.\更新复习计数器.ps1`
  - 记录某题今天复习：`.\更新复习计数器.ps1 -MarkReview -Subject 操作系统 -Chapter "第1章 计算机系统概述" -Number 03 -ReviewTopic "模块化OS的特点"`
  - 注册每日计划任务：`.\更新复习计数器.ps1 -InstallTask`（需要管理员 PowerShell）
- 不打开前端也能更新：把脚本加入 Windows 计划任务后，每天会自动写回 CSV。

## 图片处理规则

- 纯文字题：不保存截图，直接用多模态识别题干和选项，整理成 Markdown。
- 含必要图片信息的题：保留图片来源，例如树形图、图论示意图、存储结构表、矩阵、复杂代码截图。
- 图片只是纯文字载体时，录入完成后不需要继续保存截图，也不用在条目里写 `图片来源`。

## 每道错题最低记录标准

1. 日期
2. 科目
3. 王道章节
4. 题号
5. 考点
6. 错误类型
7. 正确答案
8. 原题和选项
9. 红色错误原因
10. 下次遇到同类题第一步

## 错误类型

- 概念不清
- 过程推导错
- 计算/单位错
- 审题错
- 代码边界错
- 题型陌生
- 记忆遗漏
- 时间不够
