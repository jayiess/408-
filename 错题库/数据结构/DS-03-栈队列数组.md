# DS-03 栈、队列和数组错题

## 2026-05-08｜01｜栈和队列的逻辑结构

**原题：栈和队列具有相同的（ ）。**

| 选项 | 内容 |
| --- | --- |
| A | 抽象数据类型 |
| B | 逻辑结构 |
| C | 存储结构 |
| D | 运算 |

正确答案：B

错误原因：<span style="color: red;">混淆逻辑结构、抽象数据类型、存储结构和运算。</span>

## 2026-05-08｜13｜卡特兰数与出栈序列

**原题：3 个不同元素依次入栈，能得到（ ）种不同的出栈序列。**

| 选项 | 内容 |
| --- | --- |
| A | 3 |
| B | 5 |
| C | 6 |
| D | 7 |

正确答案：B

错误原因：<span style="color: red;">忘记卡特兰数公式。</span>

公式：

```text
C_n = 1 / (n + 1) * C(2n, n)
```

## 2026-05-08｜23｜栈输出序列与 C 标识符

**原题：设栈的初始状态为空，当字符序列 `a1_` 作为栈的输入时，输出长度为 3，且可用作 C 语言标识符的序列有（ ）个。**

| 选项 | 内容 |
| --- | --- |
| A | 4 |
| B | 5 |
| C | 3 |
| D | 6 |

正确答案：C

错误原因：<span style="color: red;">没有先用栈规则列出合法出栈序列，再按 C 标识符规则筛选。</span>

合法出栈序列：`a1_`、`a_1`、`1a_`、`1_a`、`_1a`。  
可作 C 标识符：`a1_`、`a_1`、`_1a`。

## 2026-05-08｜11｜链式队列长度

**原题：与顺序队列相比，链式队列的（ ）。**

| 选项 | 内容 |
| --- | --- |
| A | 优点是队列的长度不受限制 |
| B | 优点是入队和出队时间效率更高 |
| C | 缺点是不能进行顺序访问 |
| D | 缺点是不能根据队首指针和队尾指针计算队列的长度 |

正确答案：D

错误原因：<span style="color: red;">把“能通过遍历数出来”和“能根据队首、队尾指针直接计算出来”混在一起。</span>

## 2026-05-08｜12｜最适合作队列的链表

## 2026-05-08｜07｜递归函数执行顺序

**原题：设有如下递归函数，在 `func(func(5))` 的执行过程中，第 4 个被执行的 `func` 函数是（ ）。**

```c
int func(int x) {
    if (x <= 3) return 2;
    else return func(x-2) + func(x-4);
}
```

| 选项 | 内容 |
| --- | --- |
| A | `func(2)` |
| B | `func(3)` |
| C | `func(4)` |
| D | `func(5)` |

正确答案：C

错误原因：<span style="color: red;">不清楚“被执行”的计数时机。这里每进入一次 `func(...)` 函数体，就算一个 `func` 被执行；不是等函数返回时才计数。</span>

复盘结论：

```text
要求 func(func(5))，必须先计算内层 func(5)。

第 1 个执行：func(5)
  5 > 3，所以计算 func(3) + func(1)

第 2 个执行：func(3)
  3 <= 3，返回 2

第 3 个执行：func(1)
  1 <= 3，返回 2

内层 func(5) 返回 2 + 2 = 4

外层变成 func(4)

第 4 个执行：func(4)
```

因此第 4 个被执行的是 `func(4)`。
