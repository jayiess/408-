| 题型 | 单项选择题 |
| 正确答案 | C |
| 错误类型 | 概念不清 |

**原题：下列关于算法的说法中，正确的是。**

| 选项 | 内容 |
| --- | --- |
| A | 算法的时间效率取决于算法执行所花的 CPU 时间 |
| B | 在算法设计中不允许用牺牲空间效率的方式来换取好的时间效率 |
| C | 算法必须具备有穷性、确定性等五个特性 |
| D | 通常用时间效率和空间效率来衡量算法的优劣 |

错误原因：<span style="color: red;">对算法五大特性和算法优劣评价标准的边界不够敏感。</span>

复盘结论：算法必须具备有穷性、确定性、可行性、输入、输出五个特性；评价算法效率重点看时间复杂度和空间复杂度，但评价算法优劣不能只看效率。

## 2026-05-05｜17｜时间复杂度

| 项目 | 内容 |
| --- | --- |
| 题型 | 单项选择题 |
| 正确答案 | C |
| 错误类型 | 过程推导错 |

**原题：下列程序段的时间复杂度是。**

```c
int sum=0;
for(int i=1;i<n;i*=2)
    for(int j=0;j<i;j++)
        sum++;
```

| 选项 | 内容 |
| --- | --- |
| A | O(log2n) |
| B | O(n^1/2) |
| C | O(n) |
| D | O(n^2) |

错误原因：<span style="color: red;">只看到了外层循环次数是 O(log n)，没有把每轮内层循环次数累加。</span>

复盘结论：外层 `i = 1, 2, 4, ...`，内层总次数为 `1 + 2 + 4 + ...`，数量级为 `O(n)`。

## 2026-05-05｜03｜逻辑结构与存储结构

| 项目 | 内容 |
| --- | --- |
| 题型 | 单项选择题 |
| 正确答案 | C |
| 错误类型 | 概念不清 |

**原题：下列选项中，属于逻辑结构的是。**

| 选项 | 内容 |
| --- | --- |
| A | 顺序表 |
| B | 哈希表 |
| C | 有序表 |
| D | 单链表 |

错误原因：<span style="color: red;">把顺序表的“顺序”理解成逻辑上的有序关系。</span>

复盘结论：顺序表是存储结构，有序表描述逻辑关系。
